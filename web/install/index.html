Install
Yu OS.

Add Yu Agent to Ubuntu, install from a prebuilt WSL image, or build from source.

On Ubuntu

Open Terminal on a 64-bit Ubuntu computer (Intel, AMD or ARM). You'll need administrator access and curl.

  1. Add the signed package source

  2. Install Yu Agent

    APT checks the repository signature before installing the Agent.

  3. Start your first chat

    Check that the service is active, then set up a model and open Yu Agent.

Windows / WSL

Download the Yu OS .wsl image for your computer. With WSL 2 installed, open PowerShell in the download folder and run the command below, using the filename you downloaded. No source build is needed.

Build from source

On Linux or WSL2, clone Yu OS into your home directory. You'll need Git and terminal access to github.com.

Run the build commands below from the checkout. If you already have the source, skip cloning and open that directory. These options require build tools and package access.

Windows / WSL2

In PowerShell, open the checkout folder or use the path to the built .wsl file.

Docker / OrbStack

With Docker or OrbStack running, build the headless yuos image locally.

Headless VM (experimental)

With QEMU installed, build and boot the amd64 disk. On first boot, set the password for yu, then sign in with that account.

Desktop VM / ISO (experimental)

These builds require an authorized package signer, signed App packages and a sealed Desktop Shell. They are intended for development.

For VMware, build the desktop image and attach the resulting .vmdk as an existing disk in a new VM.

To test the installer, boot the generated ISO in a VM with an empty virtual disk.

Azure

Build a fixed VHD for a Generation 2 VM. Azure sets up the administrator account and SSH key when it starts.

Already installed?

Get updates from the signed package source without reinstalling Yu OS.
