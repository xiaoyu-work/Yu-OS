yuos_sdk (Python API Reference)

Official Python SDK for Yu OS Apps (Python 3.10+). Provides @command and @desktop entry decorators, system AI calls, native file/folder dialogs, MCP server bindings, and OS helpers.

pip install yuos-sdk

@yuos_sdk.app.command(name_or_fn) -> Callable[[list[str]], Any]
#

Decorator that registers a function as a command-line operation invoked via yu app <id> <name> [args...]. Can be used bare as @command (uses the Python function's __name__) or with an explicit command name @command("name").

Parameters:
  • name_or_fn (Callable | str) – Either the decorated handler function (when used as @command) or a non-empty operation name string matching operations.<name> in app.json.
  • args (handler arg) (list[str]) – Passed to the decorated function at runtime: the validated CLI argument strings after the command name.
Returns:
The decorated function. Its return value (dict, list, str, int, bool, or None) is serialized as JSON to stdout.
Return type:
Callable[[list[str]], Any]
Raises / Errors:
ValueError – If the command name is empty or registered twice.
Example:
from yuos_sdk.app import command

@command
def summarize(args: list[str]) -> dict:
    return {"summary": args[0]}
@yuos_sdk.app.desktop(fn) -> Callable[[], Any]
#

Decorator that registers the zero-argument entry function called when the App is launched from the desktop launcher or via yu app <id> --gui. If an App only defines @command and a user launches --gui (or vice versa), the SDK automatically returns a structured unavailable-surface JSON response.

Parameters:
  • fn (Callable[[], Any]) – Zero-argument function that starts your GUI window loop (Qt, GTK, Tkinter, etc.).
Returns:
The decorated desktop entry function.
Return type:
Callable[[], Any]
Raises / Errors:
ValueError – If a default @desktop function is registered more than once.
Example:
from yuos_sdk.app import desktop

@desktop
def main() -> None:
    # Open your Qt / GTK / Tkinter window
    ...
yuos_sdk.app.run(argv=None) -> Any
#

Dispatch the current process invocation to the registered @command or @desktop function. In Python, calling run() explicitly is optional because yuos_sdk.app automatically dispatches when main.py finishes loading.

Parameters:
  • argv (list[str] | None, optional) – Optional argument vector override for unit tests. Default: None (reads YUOS_COMMAND / YUOS_ARGS_JSON / sys.argv).
Returns:
The return value of the invoked handler function.
Return type:
Any
Raises / Errors:
RuntimeError – If no matching command or desktop handler is registered.
Example:
from yuos_sdk.app import run

if __name__ == "__main__":
    run()

Return this App's isolated private data directory, creating it if it does not exist. Uses $YUOS_DATA_DIR inside a Yu OS session, or ~/.local/share/yuos-dev/apps/<id> during local development. Requires no permissions in app.json.

yuos_sdk.app.require_permission(verb, *, path=None, host=None, name=None, self_ref=None, wild=False) -> None
#

Verify at runtime that the current session holds verb for a dynamically computed scope (e.g. checking net.dial on an HTTP redirect target). Use check_permission(...) with the same arguments to return the raw decision dict without raising.

Parameters:
  • verb (str) – Capability verb to check (e.g. "net.dial", "fs.read").
  • path (str | None, optional) – Filesystem path scope. Supply at most one scope keyword.
  • host (str | None, optional) – Network host or host:port scope.
  • name (str | None, optional) – Named resource scope.
  • self_ref (str | None, optional) – App self-reference scope.
  • wild (bool, optional) – Check wildcard scope. Default: False.
Returns:
None (raises PermissionError if denied).
Return type:
None
Raises / Errors:
PermissionError – If the kernel denies the requested capability.
Example:
from yuos_sdk.app import require_permission

require_permission("net.dial", host="api.example.com:443")

Streaming, cancellation, and typed handlers

On Yu OS, the chat streaming APIs emit text as the configured model produces it. A model without native streaming can return a single piece. Treat text as provisional until the call completes successfully. Go and Rust also return the final chat response. Model calls have no SDK deadline; Yu OS stops a provider that stays silent for the configured request timeout. With YUOS_DEV_AI_URL, every SDK consumes OpenAI-compatible SSE (Rust through curl). Node chatStream rejects App functions; use chat. In local development, Go and Rust return a streamed request with App functions in one piece.

In Node MCP handlers, use await files.readFileAsync(path, context) and await files.replaceFileAsync(path, revision, content, context) to pass the MCP signal and deadline without blocking the event loop. Do not retry an interrupted commit automatically: cancellation cannot undo an accepted replacement.

Run npx yuos-tool-types app.json (Node) or call yuos_sdk::mcp::rust_tool_bindings from build.rs (Rust) to generate typed MCP handlers. Regenerate after manifest edits; runtime validation still uses the signed manifest.
